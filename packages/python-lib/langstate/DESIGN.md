Khandhas is a framework of state management for multi-agent systems. It provides a way to define agents, properties, and their relationships in a structured manner. The framework is designed to be extensible and flexible, allowing for various types of properties and dependencies.

How does state management in multi-agent systems differ from traditional state management?

1. **Dynamic Interactions**: In multi-agent systems, agents can interact with each other dynamically, leading to state changes that are not predictable in advance. Traditional state management often assumes a more static environment.
